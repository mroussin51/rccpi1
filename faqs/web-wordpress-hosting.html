What’s the best way to host static sites and WordPress on AWS?

Serve static sites from S3 and CloudFront with Route 53 DNS. For WordPress, use a hardened container or Lightsail, add page/object caching and image optimization, and schedule automated backups. Keep a staging environment to test updates before pushing to production.
