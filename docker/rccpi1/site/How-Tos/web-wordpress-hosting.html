Fast static site with HTTPS and CDN

Host on S3, front with CloudFront, and use ACM for TLS. Cache HTML carefully, compress assets, and version file names to bust caches on deploy. Add a simple CI job to invalidate changed paths only.

Steps

  1. Upload site to S3 with proper MIME types.
  2. Attach CloudFront; configure caching policies.
  3. Issue ACM cert; set HTTPS redirects.
  4. Automate cache invalidations on deploy.

Secure WordPress without the headache

Use a managed database, restrict admin access, keep plugins to essentials, and place the site behind a CDN and WAF. Keep automatic updates and daily offsite backups. Monitor login attempts and errors to catch issues early.

Steps

  1. Use RDS and least‑privilege credentials.
  2. Place behind CloudFront and managed WAF.
  3. Limit plugins; auto‑update core and themes.
  4. Daily backups; test restores quarterly.

Add a staging environment safely

Clone the site and database, disable indexing, and protect with basic auth. Route a subdomain to staging and require approvals before promoting changes. Reset data regularly to avoid drift.

Steps

  1. Clone prod; sanitize sensitive data.
  2. Block search indexing; add auth.
  3. Route staging subdomain; restrict access.
  4. Approve and promote changes via CI/CD.
