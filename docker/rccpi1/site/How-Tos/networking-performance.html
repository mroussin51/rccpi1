Make your site fast worldwide

Serve static assets from S3 and cache with CloudFront. Compress images, enable HTTP/2, and cache HTML where possible. Measure with synthetic tests across regions and fix slow TTFB by moving compute closer or optimizing origin performance.

Steps

  1. Enable CDN with sensible TTLs and cache keys.
  2. Optimize images; lazy‑load below‑the‑fold assets.
  3. Compress responses; enable HTTP/2.
  4. Track TTFB and cache hit ratio routinely.

Key figures

  • TTFB target: < 800 ms globally.

Set up HTTPS with automatic renewals

Use managed certificates (ACM) on ALB/CloudFront and redirect all HTTP to HTTPS. If terminating at the origin, automate renewals and reloads. Monitor cert expiry and include it in your standard operations checklist to avoid outages.

Steps

  1. Issue ACM certs; validate domain ownership.
  2. Attach certs to ALB/CloudFront; force HTTPS.
  3. If origin TLS: automate renewals and reloads.
  4. Monitor expiry dates and alerts.

Protect against common attacks on a budget

Enable basic DDoS protections and a minimal WAF rule set for bots and known bad patterns. Rate‑limit login endpoints, prefer OAuth/SSO, and keep origin IPs private behind load balancers to reduce exposure.

Steps

  1. Place site behind ALB/CloudFront.
  2. Enable managed WAF rules minimally.
  3. Rate‑limit or captcha login endpoints.
  4. Hide origin IPs; restrict security groups.
